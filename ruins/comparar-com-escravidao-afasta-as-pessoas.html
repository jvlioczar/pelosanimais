Início / Argumentos ruins / Objeção disfarçada

V22

"Comparar com escravidão afasta as pessoas."

Objeção disfarçada

Parecem cuidado com a estratégia ou com os animais, mas viram justificativa pronta para não mudar nada.

Por que é ruim

Pode parecer uma preocupação estratégica. O teste é simples: se ficasse comprovado que a comparação é mais eficaz para mudar a situação dos animais, você passaria a apoiá-la? Se a resposta é não, a objeção sempre foi moral, apenas com roupagem de cálculo tático.

Não há problema em ter uma objeção moral a uma tática. O problema é disfarçá-la, porque isso impede que a discordância real seja discutida.

A preocupação com a ofensa merece ser levada a sério, mas precisa ser aplicada com consistência. Ser comparado a um animal não humano só é ofensivo para quem já parte da premissa de que animais valem menos.

Como dizer melhor

Diga qual é sua objeção de verdade. Se é moral, defenda-a como moral. Se é estratégica, mostre a evidência.
